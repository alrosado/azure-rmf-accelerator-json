# Set-ARATest

## SYNOPSIS

Set operation for ARATest

## SYNTAX

### Properties (Default)

```
Set-ARATest -Id <string> [-Name <string>] [-Type <string>] [-Description <string>]
 [-TargetType <string>] [-TargetKey <string>] [-Steps <string[]>] [-RoleKey <string>]
 [-ExpectedValue <string>]
```

### Object

```
Set-ARATest -Test <Test>
```

## ALIASES

This cmdlet has the following aliases,
  {{Insert list of aliases}}

## DESCRIPTION

The cmdlet to set a test.

## EXAMPLES

### Example 1

Set-ARATest -Id "Test1" -Name "Updated Test" -Description "This is an updated test."

Updates an existing Test object in the currently connected ARA file.
