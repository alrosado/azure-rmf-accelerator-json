# Get-ARATest

## SYNOPSIS

Get operation for ARATest

## SYNTAX

### __AllParameterSets

```
Get-ARATest [-Id <string>] [-RequirementCategory <string>] [-RequirementId <string>]
 [-Type <string>] [-TargetType <string>] [-RoleKey <string>]
```

## ALIASES

This cmdlet has the following aliases,
  {{Insert list of aliases}}

## DESCRIPTION

Gets the test settings from the connected ARA file.

## EXAMPLES

### Example 1

Get-ARATest -Id "Test1"

Returns the Test object(s) from the currently connected ARA file.
