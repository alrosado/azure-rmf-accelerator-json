# Add-ARASecurity

## SYNOPSIS

Add operation for ARASecurity

## SYNTAX

### Properties (Default)

```
Add-ARASecurity -ImpactLevel <string> -Classification <string> [-Confidentiality <string>]
 [-Integrity <string>] [-Availability <string>] [-Controls <string>] [-Roles <Role[]>]
 [-Stigs <Stig[]>]
```

### Object

```
Add-ARASecurity -Security <Security>
```

## ALIASES

This cmdlet has the following aliases,
  {{Insert list of aliases}}

## DESCRIPTION

Adds a new security configuration to the connected ARA file.

## EXAMPLES

### Example 1

Add-ARASecurity -ImpactLevel "High" -Classification "Confidential" -Confidentiality "High" -Integrity "High" -Availability "High" -Controls "Control1,Control2" -Roles $roleObject -Stigs $stigObject

Creates a new Security object in the currently connected ARA file.
